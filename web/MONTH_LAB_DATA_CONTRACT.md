# Month Lab frontend ↔ backend handoff

**Canonical contract:** [`pipeline/MONTH_API.md`](../pipeline/MONTH_API.md), schema `agrinet-month-1`. The generated static JSON is now in `web/public/month-api/`: `catalog.json` and `{product_slug}/{YYYY-MM}.json`. No server or live credential is needed. The frontend uses Vite's `BASE_URL` and validates schema, selected product/month, prices, dates and modeled verdict before rendering.

The Month Lab product picker merges the entire existing `stories/catalog.json.products` index (368 entries in the current checked snapshot) with `month-api/catalog.json.products` when available. The backend catalog's observed `months` take priority for its products. Every indexed product remains selectable; no retained story or missing month JSON is **not** a finding of zero actual deals. Where the new export is absent, retained story corridors are shown only for exact catalog months as a bounded fallback. The old `stories` catalog is not treated as coverage of the backend's routed market screen.

`coverage.routed_pairs_considered` counts cached named-place road pairs considered, **not all Indian markets**. `opportunities[]` are positive retrospective modeled scenarios, not actual profits; `chains[]` are the backend's dynamic-programming hindsight sequences for one initial quintal with no compounding or repositioning. The frontend does not derive a synthetic multi-hop route. Its “unusual candidate” ranking compares only qualifying modeled candidates in the same route-month, unlike the legacy story fallback, whose median includes all valid matched buy days. Neither score is predictive. Chain totals and costs are labeled modeled, never realized.

**Verification:** the 17,458 generated product-month JSON files (368 indexed products, including 64 without calibrated cost support) were built into `dist/month-api/`; frontend unit/type checks, Chromium e2e and backend tests passed. A production-preview browser loaded the real tomato June 2022 screen (195 candidate days), showed all 368 product options, and switched to Absinthe without an error. The export is static and retrospective; it is not a live all-market API. Deployment requires separate approval.
